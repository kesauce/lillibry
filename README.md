## About The Project

<img width="1919" height="942" alt="image" src="https://github.com/user-attachments/assets/5a81389a-2321-4796-a57c-ab86454d644c" />
I was inspired by GoodReads, an application that allows you to keep track and discover books but I wanted an app that is more visual. There came the idea for lillibry, short for little library. It's a web application that allows you to store books into customisable shelves and see, visually, all the books you've saved. You can find books using an external API or add a custom book yourself, and see the details of each book. You can create how many shelves you want and add how ever many books you need. All of your information is stored in you lillibry account, so you never have to worry about losing your data.
